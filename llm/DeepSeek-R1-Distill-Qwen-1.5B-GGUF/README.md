## About DeepSeek-R1-Distill-Qwen-1.5B

**DeepSeek-R1-Distill-Qwen-1.5B** is the smallest reasoning-focused distilled model from DeepSeek AI. It demonstrates how frontier reasoning capabilities developed through pure reinforcement learning can be distilled into compact edge models, enabling explicit `<think>` scratchpads and multi-stage self-correction.

### Key Applications in Industry
- **Automated Logic Verification:** Validates business rule constraints and contract conditions prior to execution.
- **Personal Math & STEM Tutor:** Walks students through algebra, geometry, and calculus derivations step-by-step.
- **Code Debugging & Edge Cases:** Examines software functions to spot hidden race conditions and boundary errors.
- **Medical & Financial Auditing:** Constructs transparent audit trails explaining why a decision was reached.

---

## Architectural Innovations in DeepSeek-R1-Distill-Qwen-1.5B

1. **Explicit Chain-of-Thought (`<think>`):** Generates internal reasoning steps before issuing final answers, dramatically reducing hallucination.
2. **Distilled Reinforcement Learning Traces:** Inherits 800,000+ curated reasoning trajectories from DeepSeek-R1 671B.
3. **Self-Correction Capability:** Detects intermediate miscalculations and backtracks to rectify deductions.
4. **High Efficiency on Commodity CPU:** Produces 21+ tokens/sec on standard laptop processors.

## Our Project: Automated Code Verification & Math Tutor Engine

### Problem Statement
Standard SLMs consistently fail at multi-step math and code verification due to greedy token emission. An edge reasoning engine provides transparent, reliable proofs locally.

### Project Architecture & Pipeline
Our implementation in [`demo.py`](file:///home/az1z6ekx/100-opensource-models-review/llm/DeepSeek-R1-Distill-Qwen-1.5B-GGUF/demo.py) and [`run_benchmarks.py`](file:///home/az1z6ekx/100-opensource-models-review/llm/DeepSeek-R1-Distill-Qwen-1.5B-GGUF/run_benchmarks.py):
1. **Dynamic Model Loader:** Loads quantized `DeepSeek-R1-Distill-Qwen-1.5B-Q4_K_M.gguf` into RAM / VRAM using `llama-cpp-python` with automatic multi-threaded CPU and GPU offload negotiation.
2. **Context & Prompt Formatting:** Enforces the native chat template format (`DeepSeek-R1 (`<think>...</think>`)`) with strict boundary tokens.
3. **Structured Response Extraction:** Ingests domain test prompts from `data/` and parses output tokens into validated formats.
4. **Execution Telemetry:** Tracks exact time-to-first-token (TTFT), generation tokens-per-second, and total memory footprint.

## Model Export and Optimization

The model is distributed in the universal **GGUF** format (`Q4_K_M`), ready for instantaneous deployment across modern runtime backends:

### Running with llama.cpp CLI

