## 🎯 Model Haqida va "Killer Feature"

Llama-3.2-1B — Meta tomonidan bevosita smartfonlar, shaxsiy kompyuterlar va past quvvatli chekka (edge) qurilmalarda mahalliy ishlash uchun moslashtirilgan rasmiy eng kichik arxitekturadir. 

### 🌟 Asosiy Ustunliklari ("Killer Feature"):
1. **128k Uzoq Kontekst:** 1 milliard parametrli modellar ichida kamyob bo'lgan to'liq 128k kontekst oynasi (uzun hujjatlar va xatlar bilan ishlash imkoni).
2. **Meta Sifat Standarti:** Llama 3 oilasining nufuzli instruksiya intizomi, xavfsizlik filtrlari va yuqori tezlikdagi sintaksis.
3. **Ultra-Yengil Xotira:** 4-bit kvantlashda model atigi **~800 MB** xotira egallaydi, 1 GB RAM li oddiy IoT mikrokontroller yoki mini-serverda ishga tushadi.
