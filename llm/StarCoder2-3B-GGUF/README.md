## 🎯 Model Haqida va "Killer Feature"

StarCoder2-3B — BigCode konsortsiumi (Hugging Face & ServiceNow) tomonidan ishlab chiqilgan va eng toza ma'lumotlar to'plami (**The Stack v2**) asosida o'qitilgan enterprise-darajadagi kod modelidir.

### 🌟 Asosiy Ustunliklari ("Killer Feature"):
1. **100% Permissive Litsenziya:** Korxona va tijorat loyihalarida huquqiy xavf-xatarsiz (GPL yoki noaniq litsenziyali kodlardan tozalangan) foydalanish uchun 1-raqamli model.
2. **Fill-in-the-Middle (FIM):** Kod o'rtasidagi bo'shliqlarni to'ldirish, IDE ichida avtomatik autocomplete qilishda maxsus optimallashtirilgan.
3. **Kichik hajm, yuqori tezlik:** 3B parametrli model 4-bit kvantlashda bor-yo'g'i ~2 GB RAM talab qiladi va oddiy CPU da ham 20-30 tok/s tezlikda ishlaydi.
