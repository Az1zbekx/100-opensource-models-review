## 🎯 Model Haqida va "Killer Feature"

Ushbu model ochiq manbali kod modellari orasida eng mashhur **MoE (Mixture of Experts)** arxitekturasiga ega. U umumiy 16 milliard parametrga ega bo'lsa-da, har bir token generatsiyasida faqat **2.4 milliard parametr** aktivlashadi. 

### 🌟 Asosiy Ustunliklari:
1. **338 ta Dasturlash Tili:** Python, JS, C++, Rust, Go, SQL, ClickHouse, Solidity va hatto eng kamyob tillarda ham kuchli.
2. **128k Uzoq Kontekst:** Butun boshli repozitoriya kodlarini bitta kontekstga joylab, butun arxitekturani refaktoring qila oladi.
3. **MoE Samaradorligi:** 16B modelning aqlini 2.4B modelning tezligi va tejamkorligi bilan taqdim etadi.
